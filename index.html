01 — INTRODUCTION

What is Interactive Media?

Interactive media refers to media that allows users to participate by clicking, choosing, answering, or controlling content. Unlike passive media, users take action and receive a response from the system.

Passive Media

Watching a prerecorded video without controlling its content.

Interactive Media

Answering an online quiz, voting in a poll, or choosing a route on a map.

03 — INTERACTION CYCLE

How Does Interaction Work?

1

User Action

Clicks, types, chooses, or drags.

2

System Response

The screen changes or input is recorded.

3

Feedback

A result or new information appears.

4

Next Choice

The user continues, revises, or stops.

Example: Choose an answer → the system checks it → feedback appears → you decide what to review.

05 — DESIGN AND EFFECTIVENESS

Characteristics of Good Interactive Media

Clear Action

Users know what they need to do.

Purposeful

Every activity has a clear goal.

Feedback

The system provides a response or result.

User Control

Users are allowed to make choices.

Accessibility

Everyone has a fair chance to participate.

Engaging

Activities maintain attention and understanding.

Selection Criteria

  • Relevance: Is it connected to the topic?
  • Clarity: Are instructions easy to understand?
  • Accuracy: Is the information correct?
  • Usability: Is it easy to use?
  • Accessibility: Can everyone participate?
  • Privacy: Does it protect personal information?

Four Design Principles

Contrast

Makes important information stand out.

Alignment

Keeps content organized.

Repetition

Maintains consistent design.

Proximity

Places related elements together.

06 — WEBINAR APPLICATION

Interactive Media in a Webinar

Before

Use a poll to check prior knowledge.

During

Use a quick quiz or chat prompt to check understanding.

After

Use a reflection form or Q&A to gather thoughts.

Five Planning Steps

  1. Choose: Pick a suitable interactive tool.
  2. Write: Create clear instructions and a focused question.
  3. Check: Review relevance, clarity, usability, accessibility, and privacy.
  4. Test: Open the link or feature before presenting.
  5. Use Results: Discuss what the responses mean.

KEY TAKEAWAY

Interaction Should Have a Purpose.

Interactive media is not just about clicking buttons or answering questions. It should help users participate, make choices, receive useful feedback, and learn better.
